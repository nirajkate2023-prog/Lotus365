Blog Studio

Write, preview and publish posts to the Lotus365 blog. Changes are committed to content/blog/posts.json in your GitHub repository, or exported as a file you can upload to your host.

← View live blog 🔒 Private workspace ⌨️ Ctrl/⌘ + S to publish

1. Publishing connection

Needs Contents: Read and write on this repository only. The token is never sent anywhere except api.github.com.
Not connected
  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Repository access: Only select repositories → Lotus365.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else is required.
  4. Generate the token, copy it once, and paste it above.
Security: this page is public HTML. Publishing only works with your token, so keep the token private and never commit it to the repo. Leave "Remember token" unticked on shared computers. Tokens expire — regenerate when publishing starts failing with 401.
